The input file states the number of log-spaced energy points at which BEN and BEP spectra must be represented.

The input file gives the {Nuclide, Activity} inventory.  Activity unit = Bq.  Nuclide must be specify-able as either Co60 or Co-60 or CO-60 or CO60, i.e. allow flexibility in format.

The nuclide list starts after the delimiting keyword “@Start” and is terminated by the keyword “@End”.

The {Nuclide, Activity} inventory data may be tab-delimited or space-delimited or be delimited by spaces and tabs combined.  Allow flexibility.
